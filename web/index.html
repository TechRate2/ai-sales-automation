Connection guide

Lấy thông tin ở đâu

Theo tài liệu đã xác minh

Botcake

  1. Lấy `BOTCAKE_PAGE_ID` từ page/bot đang dùng trong Botcake.
  2. Lấy `BOTCAKE_API_TOKEN` trong khu vực Developer/API của Botcake admin.
  3. Dùng header `access-token` khi gọi Public API.
  4. Dùng `GET /pages/{page_id}/get_list_tag` để lấy tag ID.
  5. Dùng `POST /pages/{page_id}/flows/send_content` và `send_flow` để gửi tin/flow.

Vị trí lấy token trong giao diện Botcake cần xác minh trực tiếp trên tài khoản của anh.

Pancake POS

  1. Vào Cấu hình → Nâng cao → Kết nối bên thứ 3 → Webhook/API.
  2. Tạo `PANCAKE_POS_API_KEY`.
  3. Gọi `GET /shops` để lấy `PANCAKE_POS_SHOP_ID`.
  4. Gọi `GET /shops/{SHOP_ID}/warehouses` để lấy warehouse ID.
  5. Gọi `GET /products/variations` để lấy sản phẩm và biến thể.

Pancake POS dùng `api_key` dạng query theo OpenAPI hiện tại.

Trước khi bật thật

  1. Chạy `npm run doctor` và xử lý mọi `[FAIL]`.
  2. Capture webhook thật từ Botcake.
  3. Kiểm tra sản phẩm/tồn kho thật từ POS.
  4. Không bật đơn nháp nếu chưa xác minh status draft.
  5. Không commit `.env` lên GitHub.
